Connect your Firebase database
Your tasks will be saved to Firebase Firestore and synced across all your devices in real-time. This takes about 2 minutes to set up once.
1. Go to console.firebase.google.com
2. Click Add project → name it → create
3. Click Web icon (</>) → register app → copy the config object
4. Go to Build → Firestore Database → Create database → Start in test mode
5. Paste your config below (just the { apiKey: ... } part)
